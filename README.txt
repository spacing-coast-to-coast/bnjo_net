## Before running:

1 - You will need to get spectral images from https://hyspecnet.rsim.berlin/. 
Follow the steps for converting to .npy if using, otherwise use TIFF.
Place the hyspecnet-11k/patches in root.

2 - Specify file_type in main.py using whichever option from above.

3 - Specify batch_size and epochs in main.py.
